第一题

设 T(n) 为把 n 个盘子从起始柱 A 全部移到目标柱 C（可借助中间柱 B）所需要的最少 move 次数。

一、建立递推关系

要把最大的第 n 号盘从 A 移到 C，必须满足两个前提：

1. 在最大盘移动之前，压在它上面的 n-1 个盘子必须全部移到 B 上，否则最大盘动不了，这一步最少需要 T(n-1) 次 move。
2. 最大盘从 A 移到 C，恰好 1 次 move。
3. 最大盘移走后，还要把 B 上的 n-1 个盘子移到 C 上，这又是一个 n-1 阶 Hanoi 问题，最少需要 T(n-1) 次 move。

所以至少需要 2T(n-1)+1 次；而按「A→B，A→C，B→C」这个顺序操作恰好能达到这个次数，即下界是可达的，因此

    T(n) = 2T(n-1) + 1,   T(1) = 1

二、求解递推式

两边同时加 1，把递推式配成等比形式：

    T(n) + 1 = 2T(n-1) + 2 = 2(T(n-1) + 1)

于是 {T(n)+1} 是公比为 2 的等比数列，且 T(1)+1 = 2，所以

    T(n) + 1 = 2^(n-1) * (T(1)+1) = 2^(n-1) * 2 = 2^n

    T(n) = 2^n - 1

三、也可以用迭代（展开法）验证

    T(n) = 2T(n-1) + 1
         = 2(2T(n-2)+1) + 1 = 2^2 T(n-2) + 2 + 1
         = 2^3 T(n-3) + 2^2 + 2 + 1
         ...
         = 2^(n-1) T(1) + 2^(n-2) + ... + 2 + 1
         = 2^(n-1) + (2^(n-1) - 1)
         = 2^n - 1

四、结论

n 阶 Hanoi 塔问题至少要执行 2^n - 1 次 move 操作，时间复杂度为 O(2^n)。
验证：n=1 时 2^1-1=1 次；n=2 时 3 次（A→B，A→C，B→C）；n=3 时 7 次；n=64 时约 1.8*10^19 次。
