# 第七题

证明：同一棵二叉树的所有叶子结点，在先序序列、中序序列以及后序序列中都按相同的相对位置出现。

## 结论的精确表述

设二叉树 T 的叶子按"从上到下、同层从左到右"的空间次序排列为 `L₁, L₂, …, Lₖ`（也就是对树做一次中序/先序/后序遍历时叶子被访问到的次序）。要证：三种遍历序列中，叶子的子序列都恰好是 `L₁L₂…Lₖ`。

这里的"从左到右"指：若结点 u 在结点 v 的左侧（u 位于 v 的左子树中，或 u 的某个祖先是 v 的祖先的左孩子而 v 在对应的右子树中），则 u 的所有叶子都排在 v 的所有叶子之前。

## 证明（对树的高度作结构归纳）

记 `Pre(T)`、`In(T)`、`Post(T)` 为 T 的三种遍历序列，`Leaf(T)` 为其中只保留叶子后的子序列。

**归纳基**：T 为空树时三序列均为空，命题平凡成立；T 只有一个结点时，该结点既是根又是叶子，三种遍历序列都是单元素序列，命题成立。

**归纳假设**：对根为 T 的左、右子树的任意二叉树，命题成立，即

```
Leaf(L) = Leaf(Pre(L)) = Leaf(In(L)) = Leaf(Post(L))
Leaf(R) = Leaf(Pre(R)) = Leaf(In(R)) = Leaf(Post(R))
```

且两者内部都按空间从左到右排列。

**归纳步**：设 T 的根为 r，左子树为 L，右子树为 R。三种遍历的递归定义是

```
Pre(T)  = r · Pre(L) · Pre(R)
In(T)   = In(L) · r · In(R)
Post(T) = Post(L) · Post(R) · r
```

从中消去非叶子结点：

1. r 是分支结点（L、R 至少一个非空）时，r 不是叶子，于是

```
Leaf(Pre(T))  = Leaf(Pre(L)) · Leaf(Pre(R))  = Leaf(L) · Leaf(R)
Leaf(In(T))   = Leaf(In(L))  · Leaf(In(R))   = Leaf(L) · Leaf(R)
Leaf(Post(T)) = Leaf(Post(L)) · Leaf(Post(R)) = Leaf(L) · Leaf(R)
```

2. r 是叶子（L、R 均为空）时，三种遍历序列都是单个 r，`Leaf(T) = r`，命题也成立。

在上面第 1 种情形中，三种遍历都把**左子树的所有叶子排在前、右子树的所有叶子排在后**；结合归纳假设给出的子树内部次序，三者的叶子子序列都等于 `Leaf(L)·Leaf(R)`，也正是整棵树叶子的空间左到右次序。

由结构归纳法，命题对所有二叉树成立。∎

## 说明

- 证明只用到三条遍历定义中"先左子树后右子树"这一共同点；根在序列中的位置（前 / 中 / 后）不影响叶子的相对次序，因为根要么不是叶子，要么整棵树只有它一个结点。
- 因此题中例子成立：先序 `abc`、中序 `bac`、后序 `bca`，三者的叶子子序列都是 `b c`，相对次序一致。
- 需注意命题只对**同一棵树**而言；不同形状的树之间不存在这种一致性。
