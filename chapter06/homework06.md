# 第六题

一棵深度为 L 的满 K 叉树：第 L 层全是叶子，其余各层每个结点恰有 K 棵非空子树；按层次顺序从 1 开始编号。求四问并给出推导。

## 记号

- 根为第 1 层，层号 `m = 1..L`；
- `S_m` = 前 m 层的结点总数，`S_0 = 0`；
- 第 m 层第 j 个结点（j 从 1 起）的编号为 `S_{m-1} + j`；
- 关键恒等式：

\[
S_m=\sum_{t=1}^{m}K^{t-1}=\frac{K^m-1}{K-1},\qquad S_m=K\cdot S_{m-1}+1
\]

最后一个式子来自"第 m-1 层的每个结点恰好生出 K 个孩子，且第 m 层从第 S_{m-1}+1 号开始编号"。

## (1) 各层结点数

第 m 层的结点由第 m-1 层的 `K^{m-1}` 个结点各生 K 个而来，故

\[
N_m=K^{m-1}\quad (m=1,2,\dots,L)
\]

全树结点数

\[
N=S_L=\frac{K^L-1}{K-1}
\]

## (2) 编号为 n 的结点的双亲（n ≥ 2）

设 n 位于第 m 层，是本层第 j 个结点，即 `n = S_m + j`，`1 ≤ j ≤ K^{m-1}`。

由于同一层按从左到右编号，且每个双亲恰有 K 个孩子，第 m 层第 j 个结点属于第 m-1 层的第 `⌈j/K⌉` 个结点，故

\[
parent(n)=S_{m-1}+\left\lceil\frac{j}{K}\right\rceil
\]

由 `n-1 = (K·S_{m-1}+1+j)-1 = K·S_{m-1}+j`，得

\[
\boxed{\;parent(n)=\left\lceil\frac{n-1}{K}\right\rceil
        =\left\lfloor\frac{n-2}{K}\right\rfloor+1\;},\qquad n\ge 2
\]

（根 n=1 无双亲。）

## (3) 编号为 n 的结点的第 i 个孩子

设 n 位于第 m 层、本层第 j 个，即 `j = n - S_{m-1}`。它的 K 个孩子位于第 m+1 层，本层序号为 `K(j-1)+1 … K(j-1)+K`。第 i 个孩子的编号为

\[
S_m+K(j-1)+i=K\cdot S_{m-1}+1+K(n-S_{m-1}-1)+i
\]

\[
\boxed{\;child(n,i)=K(n-1)+1+i\;},\qquad 1\le i\le K
\]

存在条件：`1 ≤ i ≤ K` 且 `child(n,i) ≤ N`（即 n 不是最后一层的结点）。

## (4) 编号为 n 的结点有右兄弟的条件及右兄弟编号

把 n 写成"父结点 p 的第 i 个孩子"：由 (3) 的结论 `n = K(p-1)+1+i`，即

\[
n-1=K(p-1)+i,\qquad 1\le i\le K
\quad\Longrightarrow\quad
i=((n-2)\bmod K)+1
\]

- 若 `i = K`（n 是父结点的最后一个孩子），n 没有右兄弟；
- 若 `i < K`（n 不是最后一个孩子），按层次编号，它的右兄弟紧邻其右，编号为 `n+1`。

`i = K` 等价于 `(n-1) mod K = 0`，于是

\[
\boxed{\;\text{n 有右兄弟} \iff n\ge 2,\;(n-1)\bmod K\ne 0,\; n<N\;}
\]

此时右兄弟编号为

\[
\boxed{\;n+1\;}
\]

特别地 K=2 时，"n 为偶数且 n < N"的结点才有右兄弟（左孩子有右兄弟，右孩子没有）。

## 验算（K=3, L=4）

各层结点数：1, 3, 9, 27；总数 `N = (3^4-1)/(3-1) = 40`。

| 检验 | 公式结果 | 说明 |
|:---|:---|:---|
| parent(15) | ⌈14/3⌉ = 5 | 5 的孩子：13,14,15 ✔ |
| child(5,2) | 3×4+1+2 = 15 | 同上 ✔ |
| n=15 的右兄弟 | 14 mod 3 = 2 ≠ 0 → 16 | parent(16)=⌈15/3⌉=5 ✔ |
| n=7 的右兄弟 | 6 mod 3 = 0 → 无 | 7 是 2 的第 3 个孩子 ✔ |

附：由 `S_m ≥ n` 可得结点 n 的层号

\[
m=\left\lceil \log_K\left(n(K-1)+1\right)\right\rceil
\]

例如 K=2、n=5 时 `m = ⌈log₂7⌉ = 3`，与层序编号 4,5,6,7 位于第 3 层一致。
