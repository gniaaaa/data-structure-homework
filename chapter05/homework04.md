第四题

已知广义表 L = ((a,b),(c,d))。要求：用 Head 和 Tail 把原子 c 分离出来，
并求 L 的长度和深度。

## 一、分离原子 c

思路：c 是 L 的第二个元素 (c,d) 的表头，所以先用 Tail 跳过 (a,b)，
再取 Head 得到 (c,d)，最后取 Head 落到 c 上。

```
   L              = ((a,b),(c,d))
   Tail[L]        = ((c,d))       去掉表头 (a,b)
   Head[Tail[L]]  = (c,d)         取表头，得到第二个子表
   Head[Head[Tail[L]]] = c        再取表头，得到原子 c
```

即

```
   c = Head[Head[Tail[L]]]
```

逐步说明：

| 步骤 | 表达式 | 结果 |
|:---|:---|:---|
| ① | Tail[((a,b),(c,d))] | ((c,d)) |
| ② | Head[((c,d))] | (c,d) |
| ③ | Head[(c,d)] | c |

（顺带一提，若想取 d，则用 `Head[Tail[Head[Tail[L]]]]`：
Tail[L] = ((c,d))，Head 得 (c,d)，Tail 得 (d)，Head 得 d。）

## 二、L 的长度

长度 = 最外层元素的个数（只数第一层，不展开子表）。

L = ((a,b),(c,d)) 的最外层元素是 (a,b) 和 (c,d) 两个子表，

```
   Length(L) = 2
```

## 三、L 的深度

深度 = 展开后括号的最大嵌套层数（等价定义：原子深度为 0，空表深度为 1，
表的深度 = 1 + 各元素深度的最大值）。

```
   L = ( ( a , b ) , ( c , d ) )
        └─┘└─────┘   └─────┘
        第1层        第2层
```

- (a,b) 的元素都是原子，深度为 1；
- (c,d) 同理，深度为 1；
- L 的深度 = 1 + max(1, 1) = 2。

```
   Depth(L) = 2
```

## 四、结论

| 项目 | 结果 |
|:---|:---|
| 分离 c 的表达式 | `Head[Head[Tail[L]]]` |
| L 的长度 | 2 |
| L 的深度 | 2 |

注意区分：L 的**长度是 2**（只有两个元素），而它的**深度也是 2**（两层括号）。
如果写成 L = ((a,b),(c,d),e)，长度变成 3，深度仍是 2；
如果写成 L = (((a,b)),(c,d))，深度就变成 3 了。
